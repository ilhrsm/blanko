[배포 방법 - 순서대로 딱 3단계]

1) 이 폴더 안의 파일을 전부 기존 프로젝트(깃허브 저장소)에 덮어쓰고 push 하세요.
   -> Vercel 등으로 연결돼 있으면 자동으로 재배포됩니다.
   (.env / 환경변수는 건드리지 마세요. 기존 것 그대로 사용)

2) Firestore 규칙 게시 (이걸 해야 판매자에게 주문이 보입니다)
   방법 A) Firebase 콘솔 -> Firestore Database -> 규칙 탭 -> firestore.rules 내용 전체를 붙여넣고 [게시]
   방법 B) 터미널: firebase deploy --only firestore:rules

3) 판매자 계정 로그인 -> 가판대 꾸미기(에디터) -> 상점 정보 -> 입금 계좌 정보 입력 -> 저장

* 기존에 들어왔던 주문은 sellerId가 없어서 안 보입니다.
  Firebase 콘솔 -> Firestore -> orders -> 해당 주문에 sellerId(판매자 uid) 필드를 추가하면 보입니다.
